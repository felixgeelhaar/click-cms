# Ihre Website bearbeiten — Deutsch

[English](editor-en.md) · [Vollständiges Handbuch](handbook-de.md)

Diese Anleitung hilft Ihnen, Texte und Bilder Ihrer Website zu ändern. Sie müssen nichts installieren und keinen Code schreiben. Sie benötigen die Anmeldeadresse, Ihren Benutzernamen und Ihr Passwort. Diese erhalten Sie von der Person, die Ihre Website betreut.

## Einen Text ändern

1. Öffnen Sie Ihre Anmeldeadresse und melden Sie sich an. Wählen Sie ein neues Passwort, falls Sie dazu aufgefordert werden.
2. Klicken Sie im Menü auf **Pages** (Seiten).
3. Suchen Sie die gewünschte Seite und klicken Sie auf **Edit** (Bearbeiten).
4. Suchen Sie den Text. Eine Seite besteht aus **Abschnitten**, zum Beispiel einer Überschrift, einem Bild oder einem Textblock. Öffnen Sie den passenden Abschnitt.
5. Ändern Sie den Text und klicken Sie auf **Save** (Speichern).
6. Öffnen Sie die Vorschau und lesen Sie Ihre Änderungen.
7. Wenn Besucher die Änderung sehen sollen, klicken Sie auf **Publish** (Veröffentlichen). Fehlt diese Schaltfläche, bitten Sie die für die Freigabe zuständige Person darum.
8. Öffnen Sie die öffentliche Website und prüfen Sie das Ergebnis.

**Fertig, wenn:** Besucher den richtigen Text auf der richtigen Seite sehen.

## Was bedeuten Speichern und Veröffentlichen?

| Aktion | Was passiert? |
|---|---|
| **Save** (Speichern) | Ihre Änderungen bleiben als Entwurf erhalten. Besucher sehen sie noch nicht. |
| Vorschau | Sie prüfen den Entwurf, bevor Besucher ihn sehen. |
| **Publish** (Veröffentlichen) | Die gespeicherten Änderungen werden für Besucher sichtbar. |
| Veröffentlichung zurückziehen | Besucher sehen die Seite nicht mehr. Sie können sie weiter bearbeiten. |
| **Delete** (Löschen) | Die Seite wird entfernt. Fragen Sie nach, wenn Sie sie nur ausblenden möchten. |

Ist die Seite bereits veröffentlicht, bleibt beim Speichern die bisherige öffentliche Fassung sichtbar. Die Meldung oben im Editor zeigt, ob Änderungen noch auf die Veröffentlichung warten.

## Ein Bild ändern

1. Öffnen Sie die Seite und den Abschnitt mit dem Bild.
2. Öffnen Sie die Bildauswahl. Wählen Sie ein Bild oder laden Sie eines hoch, sofern Ihr Konto dies erlaubt.
3. Beschreiben Sie kurz, was ein aussagekräftiges Bild zeigt. Zum Beispiel: „Zwei Teammitglieder arbeiten im Labor.“
4. Prüfen Sie die Vorschau. Ist der wichtige Bildteil auch auf einem Handy sichtbar?
5. Speichern und veröffentlichen Sie die fertige Änderung.

Bewahren Sie das Originalbild sicher auf. Löschen Sie ein Bild nicht aus **Media** (Medien), nur weil Sie es von einer Seite entfernt haben. Es kann auf anderen Seiten noch verwendet werden.

## Eine andere Sprache bearbeiten

Hat Ihre Website mehrere Sprachen, wählen Sie vor dem Bearbeiten die gewünschte Sprache. Übersetzen Sie die passenden Felder. Speichern Sie diese Fassung, prüfen Sie die Vorschau und veröffentlichen Sie sie. Öffnen Sie anschließend die öffentliche Seite in dieser Sprache. Wiederholen Sie die Schritte für jede Sprache, die geändert werden soll.

## Eine Nachricht oder einen ähnlichen Eintrag hinzufügen

Manche Websites verwalten Nachrichten, Personen oder Termine unter **Collections** (Sammlungen). Eine Sammlung ist eine Liste gleichartiger Einträge.

1. Klicken Sie auf **Collections** und wählen Sie die passende Liste.
2. Erstellen Sie einen Eintrag oder öffnen Sie einen vorhandenen.
3. Füllen Sie die Felder aus. Beachten Sie die als erforderlich markierten Felder.
4. Speichern Sie, prüfen Sie eine verfügbare Vorschau und veröffentlichen Sie den Eintrag oder bitten Sie um Freigabe.
5. Prüfen Sie, wo der Eintrag auf Ihrer Website erscheint.

Namen und Felder hängen von Ihrer Website ab. Fragen Sie Ihre Website-Betreuung, wenn Sie die passende Liste nicht finden.

## Einen Fehler korrigieren

Haben Sie noch nicht veröffentlicht, korrigieren und speichern Sie den Entwurf. Benötigen Sie eine frühere gespeicherte Fassung, öffnen Sie den Seitenverlauf. Prüfen Sie die gewünschte Fassung vor dem Wiederherstellen. Prüfen Sie den wiederhergestellten Entwurf vor der Veröffentlichung.

Meldet der Editor, dass jemand anderes die Seite geändert hat, kopieren Sie Ihren noch nicht fertigen Text an einen sicheren Ort. Stimmen Sie die Änderungen mit der anderen Person ab und laden Sie die aktuelle Seite, bevor Sie weiterarbeiten.

## Wenn etwas nicht funktioniert

| Problem | Was Sie tun können |
|---|---|
| Die Anmeldung klappt nicht | Prüfen Sie Anmeldeadresse und Benutzernamen. Bitten Sie bei einem verlorenen Passwort Ihre Website-Betreuung um ein neues. |
| Publish fehlt | Fragen Sie die für die Freigabe zuständige Person. Ihr Konto darf möglicherweise nur Entwürfe vorbereiten. |
| Die Website zeigt den alten Text | Prüfen Sie, ob Sie die richtige Sprache veröffentlicht haben. Laden Sie die öffentliche Seite neu. Bleibt der Text alt, fragen Sie Ihre Website-Betreuung. |
| Eine neue Seite fehlt im Menü | Bitten Sie einen Administrator, den Menülink hinzuzufügen. |
| Ein Bild lässt sich nicht hochladen | Lesen Sie die Fehlermeldung. Versuchen Sie ein kleineres geeignetes Bild oder fragen Sie Ihre Website-Betreuung. |

Nennen Sie Ihrer Website-Betreuung die Seitenadresse, Ihre Schritte und die angezeigte Meldung. Geben Sie Ihr Passwort niemals weiter.

## Gemeinsam ausprobieren

Bitten Sie Ihre Website-Betreuung um eine Übungswebsite mit einer Beispielseite. Ändern Sie einen Satz, speichern Sie, prüfen Sie die Vorschau und veröffentlichen Sie. Kontrollieren Sie die öffentliche Seite gemeinsam. Üben Sie das Löschen nicht auf der echten Website.

Für eine längere Übung beginnen Sie mit [Demo 1](demos-de.md#demo-1-seite-bearbeiten-und-prüfen). Ihre Website-Betreuung kann die Übungswebsite vorbereiten. Die Befehle zur Einrichtung können Sie überspringen.
